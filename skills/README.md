# Paquete de Skills de Inteligencia Artificial — ServiSmart SaaS

Este directorio contiene las **7 Skills de Desarrollo y Automatización de Agentes de IA** configuradas específicamente para la plataforma **ServiSmart SaaS**.

## 📦 Lista de Skills Instaladas:

1. **`saas-frontend-architect`**: Diseño de dashboards en React/Next.js, componentes de secretaría y selector de técnicos libres con TailwindCSS.
2. **`saas-database-backend`**: Arquitectura relacional PostgreSQL/Supabase, esquemas SQL y transacciones de clientes y órdenes.
3. **`warranty-alarm-automation`**: Motor de disparo automático de las 3 alarmas de garantía (Días 1, 60 y 85) con Cron Jobs.
4. **`whatsapp-integration-engine`**: Plantillas y conectores para envío de órdenes digitales y confirmaciones al cliente por WhatsApp.
5. **`pdf-service-order-generator`**: Generador de Órdenes de Servicio y Fichas Técnicas de 1 página descargable/imprimible en PDF.
6. **`clean-code-documenter`**: Estándares de Clean Code, tipado TypeScript y comentarios obligatorios en lógica crítica para el Ing. Líder.
7. **`saas-product-strategy`**: Modelo de negocio, pricing en Pesos Colombianos ($4M setup + $600k trimestral) y cálculo de ROI.

---
*Configuradas para uso directo en Antigravity, Claude Code, Cursor y agentes autónomos de IA.*
